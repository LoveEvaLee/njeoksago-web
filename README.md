'온전한 밤'에서 온 이름입니다. 꿈 이야기를 적으면, 전통 해몽 문헌에서 구조화한 근거를 대조해 **길 · 흉 · 혼합 · 중립 · 판정 유보** 다섯 가지 중 하나로 판정해 주는 웹 서비스입니다.

**▶ 바로 써 보기: https://loveevalee.github.io/onbam-web/**

## 무엇이 다른가요

흔한 꿈해몽 콘텐츠는 두 가지 중 하나로 흐르기 쉽습니다. 듣기 좋은 말만 골라 주거나("대박 날 꿈이에요!"), 출처를 알 수 없는 해석을 단정적으로 말하거나. 온밤는 반대로 갑니다.

- **좋은 신호와 조심 신호가 같이 있으면, 같이 보여줍니다.** 한쪽으로 몰지 않습니다.
- **모든 판정에 근거 목록이 따라붙습니다.** 어떤 문헌 계보가 어떤 조건에서 그렇게 읽는지, 일치도가 몇 점인지 화면에 그대로 공개됩니다.
- **근거가 얇으면 판정하지 않습니다.** 억지 해석 대신 "판정 유보"를 내리고, 상징 사전으로 조건별 읽기를 보여드립니다.
- **같은 꿈은 언제나 같은 판정이 나옵니다.** 판정은 언어 모델이 아니라 결정적 코드가 계산하기 때문입니다.

## 이렇게 쓰시면 됩니다

사이트를 열고 꿈을 평소 말하듯 적으면 됩니다. 핵심 전개(누가 · 어떻게 됐는지 · 결말)를 적을수록 판정이 정확해집니다.

```
밤길에 강도를 만났는데, 누군가 나타나 나를 구해줬어      ← 전개가 있는 서술 (판정까지 계산)
뱀 꿈                                                   ← 단어만 적으면 상징 사전 모드로
아들을 잃어버렸다가 다시 찾는 꿈을 꿨어                  ← 결말이 판정을 가릅니다
```

## 결과는 이렇게 나옵니다

판정 화면은 위에서부터 이렇게 읽으시면 됩니다.

| 영역 | 보여주는 것 |
|---|---|
| **판정 배지** | 길몽 · 흉몽 · 혼합 · 중립 · 판정 유보 — 판정 사유 한 줄과 함께 |
| **BALANCE** | 길(-1)~흉(+1) 저울 눈금 — 근거 가중치 합산 결과의 위치 |
| **장면별 읽기** | 꿈 문장을 의미 단위로 쪼개, 장면마다 어떤 상징이 읽혔고 전통 자료가 뭐라고 보는지 |
| **그래서, 이 꿈은** | 판정을 한 문단으로 — 꿈과 조건이 전부 일치한 근거만 인용합니다 |
| **근거 로그** | 판정에 들어간 근거 전부 — 방향 · 등급 · 일치도 · 근거 분류 |

다섯 가지 판정이 각각 언제 나오는지는 이렇습니다.

| 판정 | 언제 나오나요 |
|---|---|
| 길몽 / 흉몽 | 한 방향 근거가 뚜렷하게 우세하고, 확실한 근거(완전 일치 또는 2계보 합의)가 받칠 때 |
| 혼합 | 길 · 흉 근거가 함께 있고 어느 쪽도 압도하지 못할 때 — 억지로 정하지 않습니다 |
| 중립 | 길흉을 가를 사건 없이 일상의 잔상에 가까울 때 |
| 판정 유보 | 근거 총량이 기준에 못 미칠 때 — 대신 상징 사전과 참고 읽기를 드립니다 |

## 알아두실 점

- **미래를 맞히는 서비스가 아닙니다.** 판정은 "전통 자료가 이 꿈을 읽어온 방향"이지, 앞일의 예측이 아닙니다. 화면에도 그렇게 적혀 있습니다.
- **적으신 꿈 내용은 서버로 전송되지 않습니다.** 이 사이트는 정적 페이지라, 분석은 브라우저 안에서만 이루어지고 기록도 브라우저(localStorage)에만 남습니다. 방문 통계(익명 집계) 외에 수집하는 것이 없습니다.
- **지식베이스는 자동으로 갱신되지 않습니다.** 새 해석 규칙은 전부 사람 검수를 거친 뒤에만 들어갑니다.
- Phase 0 시험판입니다. 상징 사전에 없는 꿈은 판정이 유보될 수 있고, 그 표현은 다음 업데이트 후보로 올라갑니다.

→ 판정이 실제로 어떻게 계산되는지 궁금하시면 [동작 원리 문서](docs/how-it-works.md)를 보세요.

## 저장소 구성

```
onbam-web/
├── index.html        앱 전체 (단일 파일 — 추출·판정 엔진 포함)
├── kb.json           판정 지식 스냅샷 (상징 사전 · 해석 규칙 · 판정 계수)
├── assets/           소개 모션그래픽
├── docs/             동작 원리 설명
├── CHANGELOG.md      공개판 변경 이력
└── LICENSE
```

지식베이스 원천 데이터(문헌 대조 작업장)와 수집 파이프라인은 비공개 저장소에서 관리하며, 이곳에는 배포용 산출물만 올라옵니다.
